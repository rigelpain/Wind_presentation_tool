# 指示書: コントロール画面「スライド」の枠

- 日付: 2026-10-11
- 案件: プレゼンツール
- 作成: 本社（開発の責任者の代行）
- 先に読む: `docs/briefs/10_コントロール画面_共通.md`、`src/engine/lesson.ts`、`src/engine/types.ts` の `ShowSettings` `SceneOverride` `Transition` `WipeMode`

## 1. 納品物

`src/control/SlidesPanel.tsx`（＋`SlidesPanel.css`）。export `SlidesPanel`（props なし）は変えない。

## 2. 中身

場面（スライド）の一覧。並びは `orderedScenes(getStore().lesson, state.settings)`（飛ばす場面も含む）。1行に1場面。

1行に出すもの:
- 実際に進む順の番号（`index + 1`。飛ばす場面は「—」）、場面の名前（`scene.title`）、部品の種類（`scene.kind`、小さく灰色）
- いま映している場面（`index === state.sceneIndex`）は行の地を明るく（`#f1ede4` の地に `#1b1a18` の字）。終わった場面は字を灰色に
- 行の名前をクリック → `dispatch({ type: 'goto', index })`（飛ばす場面はクリックしても何もしない）
- 「飛ばす」のチェック → `dispatch({ type: 'settings', patch: { skipped } })`。いま映している場面も飛ばせる（エンジンが次の場面へ移す）
- 並べ替え: 行をドラッグして別の行の上に落とすと、その位置に移る。あわせて行ごとに「↑」「↓」のボタン。どちらも `dispatch({ type: 'settings', patch: { order } })`。`order` は飛ばす場面も含めた全部の id の並び
- 行を開く（行の右の「▸」で開閉。開いた行は1つでよい）と、その場面の上書きを変える欄:
  - 切り替え: 選択欄「授業のまま / カット / 黒を挟む / 重ねる / 横すべり」→ `dispatch({ type: 'scene-override', sceneId, patch: { transition } })`（「授業のまま」は `transition: undefined`）。いまの値は `state.settings.overrides[id]?.transition`。授業のままのとき、選択欄の横に実際の値（`scene.transition`）を小さく出す
  - ワイプ: 選択欄「授業のまま / 2人 / 解説を大きく / 進行だけ / 解説だけ / カメラを隠す」→ `patch: { wipe }`
  - 音楽: 選択欄「授業のまま / 止める / （曲の名前の一覧）」→ `patch: { music }`（授業のまま は `undefined`、止める は `'stop'`、曲は曲の id）。曲の一覧は `useTracks()`（`src/media/audio.ts`）
  - 台本のメモ（`scene.notes`）を読むだけで小さく出す
- 一覧の上に「並びを元に戻す」ボタン（`confirm` のあと `dispatch({ type: 'settings', patch: { order: null, skipped: [], overrides: {} } })`）と、短い説明（「ドラッグか ↑↓ で並べ替え。チェックで飛ばす。変えた並びは授業のデータには書き戻さず、このPCに残ります」）

## 3. 触ってよいファイル

`src/control/SlidesPanel.tsx`、`src/control/SlidesPanel.css` だけ。

## 4. 完成の条件

1. tsc と vite build が通る
2. 一覧が `orderedScenes` の順で、番号・名前・種類・いまの場面・終わった場面が上のとおりに出る
3. クリックで goto、飛ばす のチェック、ドラッグと ↑↓ の並べ替え、上書きの3つの選択欄、並びを元に戻す、がそれぞれ上の action を dispatch する
4. 並べ替えの `order` が、飛ばす場面も含めた全部の id になっている（数が `getStore().lesson.scenes.length` と同じ）

## 5. 妥協しない点

- 授業のもとのデータ（`src/lessons/*`）を書き換えない。並び・飛ばし・上書きは状態の settings だけで持つ
