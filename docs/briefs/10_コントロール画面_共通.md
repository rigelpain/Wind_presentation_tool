# 指示書の共通（コントロール画面の枠）

- 日付: 2026-10-11
- 案件: プレゼンツール
- 作成: 本社（開発の責任者の代行）
- もと: 代表の言葉（2026-10-11）「ツールは表示する画面（プロジェクターやオンラインでの画面共有）、コントロール画面の２つを用意し連動するようにしてください。コントロール画面ではスライド順やカメラ・ワイプコントロール、時計の表示、音楽の設定、トランジションの設定などできるようにしてほしい」

## 1. いまの作り

- 表示画面 `http://localhost:5173/`（`src/stage/Stage.tsx`）と、コントロール画面 `http://localhost:5173/#/control`（`src/control/Control.tsx`）。同じ状態を BroadcastChannel で共有し、どちらで操作しても連動する
- コントロール画面の右側にタブが4つあり、中身の枠が4つの部品になっている。いまは仮の部品。**作業員はこの枠の中身を作る**
  - `src/control/SlidesPanel.tsx`（スライド）／`CameraPanel.tsx`（カメラ・ワイプ）／`MusicPanel.tsx`（音楽）／`SettingsPanel.tsx`（切り替え・時計）
- 枠は幅およそ 380〜520px、高さは画面に合わせて伸び、はみ出す分は縦に巻き取る（外側が `overflow: auto`）

## 2. 使うもの（もうある）

| 何 | どこ |
|---|---|
| 状態を読む | `useShow()`（`src/engine/store.ts`）。型は `src/engine/types.ts` の `ShowState`。設定は `state.settings`、音楽は `state.music`、ワイプは `state.wipe` |
| 状態を変える | `dispatch(action)`（`src/engine/store.ts`）。使える action は `types.ts` の `Action` |
| 実際に進む授業（並び替え・飛ばしを当てたもの） | `useLesson()`（`store.ts`） |
| 飛ばす場面も含めた並び | `orderedScenes(getStore().lesson, state.settings)`（`src/engine/lesson.ts`）。`getStore().lesson` は授業のもとのデータ |
| 1秒ごとなどの描き直し | `useNow(ms)`（`store.ts`） |

## 3. 決まり

- 見た目はコントロール画面の決まりに合わせる。地は暗い（`styles.css` の `.control` の中。ボタン・入力欄・選択欄は、もう暗い地の見た目になっている）。枠の外側は `<div className="c-panel">`、小見出しは `<h3>`、説明は `<p className="hint">`
- 部品の CSS は `src/control/<部品名>.css` に書き、部品の先頭で import する。クラス名は部品名で始める（例 `.slides__row`）。`styles.css` は触らない
- 文字は 13〜16px。この画面は発表者だけが見るので、舞台の 32px の決まりは当てない
- 操作したら、すぐ表示画面に効く（dispatch するだけでよい。保存や送信の処理を自分で書かない）
- 本番中に誤って押さないよう、消す・最初に戻す のような取り返しのつかない操作は `confirm` で確かめる
- **触らない**: `src/engine/*`、`src/stage/*`、`src/control/Control.tsx`、`src/styles.css`、`src/media/*`、`src/wipe/*`、ほかの作業員の部品、`package.json`。足りない機能は「責任者に確認したいこと」に書く

## 4. 確かめ方

1. `npx tsc --noEmit` がエラーなしで通る
2. `npx vite build --outDir <scratchpad の中>/wind-check-<番号>` が通る
3. ブラウザは使わない（ほかの作業員と同じ画面を取り合うため）。見た目と動きの確認は監視役が行う
