## 1. 納品物

`src/control/SettingsPanel.tsx`（＋`SettingsPanel.css`）。export `SettingsPanel`（props なし）は変えない。

## 2. 中身（上から）

1. **切り替え（トランジション）**
   - 「場面に指定がないときの切り替え」: 4つのボタン（ラジオのように1つだけ選べる）「カット / 黒を挟む / 重ねる / 横すべり」→ `dispatch({ type: 'settings', patch: { defaultTransition } })`（`'cut' | 'black' | 'fade' | 'slide'`）。選んでいるものに `className="is-on"`
   - 各ボタンの下か横に一言: カット「すぐ切り替える」、黒を挟む「区切りを作る。演出として記録する」、重ねる「前の画面と重ねて替える」、横すべり「次が右から入る。演出として記録する」
   - 「切り替えの長さ」: スライダー 200〜1500ms、刻み 50 → `patch: { transitionMs }`。横に「0.50秒」。説明「授業設計の目安は 0.4〜0.6秒」
   - 説明（小さく）「場面ごとの切り替えは『スライド』の枠で変えられます」
2. **時計**
   - 「授業の長さ」: 数の入力欄（分、5〜180）→ `patch: { durationMin }`。空にすると `null`（授業のデータのまま）。いまの実際の長さ（`useLesson().durationMin`）を横に
   - 「表示画面に出す時計」: 4つのボタン「出さない / 残り時間 / 経過時間 / いまの時刻」→ `patch: { stageClock: 'none' | 'remaining' | 'elapsed' | 'time' }`。説明「表示画面の左上に小さく出ます。生徒にも見えます」
   - 「授業を始める」（`dispatch({ type: 'start' })`。もう始まっていれば押せない・「開始 9:02」のように始めた時刻を出す）
3. **設定を元に戻す**: ボタン（`confirm` のあと `dispatch({ type: 'settings', patch: { defaultTransition: 'cut', transitionMs: 500, durationMin: null, stageClock: 'none' } })`）。並び・ワイプの設定は戻さない

## 3. 触ってよいファイル

`src/control/SettingsPanel.tsx`、`src/control/SettingsPanel.css` だけ。

## 4. 完成の条件

1. tsc と vite build が通る
2. 上の 1〜3 がそろい、それぞれ書かれた action を dispatch する
3. 授業の長さの入力欄で、範囲外（4 や 200）を入れたときは 5〜180 に収めてから送る。空なら `null`。その変換を関数に切り出し、''・'4'・'30'・'200'・'abc' で null・5・30・180・null になることを node で確かめて報告に書く
