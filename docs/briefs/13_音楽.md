# 指示書: コントロール画面「音楽」の枠

- 日付: 2026-10-11
- 案件: プレゼンツール
- 作成: 本社（開発の責任者の代行）
- 先に読む: `docs/briefs/10_コントロール画面_共通.md`、`src/media/audio.ts`、`src/media/MusicPlayer.tsx`、`src/engine/types.ts` の `MusicState`、`src/engine/reducer.ts` の `musicPosition`

## 1. 納品物

`src/control/MusicPanel.tsx`（＋`MusicPanel.css`）。export `MusicPanel`（props なし）は変えない。

## 2. 前提

- 曲はこのブラウザの IndexedDB に置く（`addTracks` など）。鳴らすのは `MusicPlayer`（もう表示画面とコントロール画面の両方にある）。鳴らす窓は `state.music.output`
- 曲の位置は `musicPosition(state.music)`。鳴らしている窓の様子は `useMusicStatus()`（`duration`、`blocked`）
- 授業設計では「音は使わない」が既定だった。代表の指示で音楽を足すが、**既定は鳴らさない**（曲を入れて再生を押したときだけ鳴る）

## 3. 中身（上から）

1. **いまの曲**: 曲の名前（なければ「曲を選んでいません」）。ボタン「再生」（`music-play`）／「一時停止」（`music-pause`）を、`state.music.playing` で入れ替える。ボタン「止める」（`music-stop`、頭に戻る）
   - 位置のバー: `<input type="range">`、0〜`duration`（`useMusicStatus()?.duration`。わからなければ 0 で動かせない）。値は `musicPosition(state.music)`（`useNow(250)` で描き直す）。動かしたら `dispatch({ type: 'music-seek', sec })`。横に「1:23 / 3:45」
   - `useMusicStatus()?.blocked` が true のとき、赤い地で「ブラウザが自動再生を止めています。{表示画面 / この画面} を一度クリックしてください」（`state.music.output` で言い分ける）
   - `useMusicStatus()` が null で `state.music.playing` のとき、灰色で「鳴らす窓が開いていません」
2. **音量など**:
   - 音量: スライダー 0〜1、刻み 0.05 → `dispatch({ type: 'music-set', patch: { volume } })`。横に「60%」
   - 「くり返す」チェック → `patch: { loop }`
   - フェード: 選択欄「なし / 0.5秒 / 1秒 / 1.5秒 / 3秒」→ `patch: { fadeMs }`（0 / 500 / 1000 / 1500 / 3000）
   - 鳴らす窓: 選択欄「表示画面（画面共有で音を送るとき）/ この画面（手元で鳴らすとき）」→ `patch: { output: 'display' | 'control' }`
3. **曲の一覧**: `useTracks()` の曲を1行ずつ。行に、名前（クリックで名前を直せる入力欄に変わり、Enter で `renameTrack`）、「流す」ボタン（`dispatch({ type: 'music-play', trackId })`）、「消す」ボタン（`confirm` のあと `removeTrack`。消す曲が `state.music.trackId` なら先に `music-stop`）。いま選ばれている曲の行は明るく
   - 曲の足し方: 「曲を足す」のファイル選択（`accept="audio/*" multiple`）と、この枠への音のファイルのドロップ → `addTracks(files)`
   - 一覧の下に小さく「曲はこのPCのブラウザの中に置きます。場面ごとに流す曲は『スライド』の枠で決められます。著作権のある曲は、授業で使ってよいか確かめてから入れてください」

## 4. 触ってよいファイル

`src/control/MusicPanel.tsx`、`src/control/MusicPanel.css` だけ。

## 5. 完成の条件

1. tsc と vite build が通る
2. 上の 1〜3 がそろい、それぞれ書かれた関数か action を呼ぶ
3. 位置の表示が `musicPosition` と `useNow` で進み、シークが `music-seek` を送る
4. 自動再生が止められたとき・鳴らす窓がないときの文言が上のとおり
5. 時刻の形（分:秒、秒は2桁）を関数に切り出し、0・59.9・60・225 秒で「0:00 / 0:59 / 1:00 / 3:45」になることを node で確かめて報告に書く

## 6. 妥協しない点

- 曲を外へ送らない。勝手に鳴らさない（再生は、再生・流す のボタンか、スライドの枠で決めた場面に入ったときだけ）
