## 2. 場面「timer」（残り時間の大きな数字）

授業の「制作4分」で使う。全画面に大きな数字。

props:

```ts
interface TimerProps {
  heading?: string;      // 例「制作時間」。数字の上に小さく
  seconds?: number;      // 既定 240
  endText?: string;      // 0 になったとき数字の下に出す。既定「時間です」
}
```

- 段階は2つ。`steps: () => [[], ['countdown']]`
  - 段階0: 数字は `seconds` のまま（例「4:00」）で止まっている。数字の下に小さく「→ で始める」は**出さない**（生徒に見える）
  - 段階1: `stepAt` から数え始め、残りを `分:秒`（秒は2桁）で出す。0 で止まり、`endText` を出す
- 残り30秒になっても**色を変えない**、点滅しない、音なし（授業設計 5.5）
- 数字の字の大きさは 1920×1080 の座標で **360px 以上**、`font-variant-numeric: tabular-nums`（桁の幅が変わって数字が揺れないように）
- R（もう一度）で最初から数え直す（`stepAt` が更新されるので、計算を `stepAt` 起点にしていれば自然にそうなる）
- ワイプ（左下・右下、高さ約 320px）と重ならない位置に数字を置く。目安は画面の上から 60〜65% までに収める

## 3. 場面「board」（数のボード）

挙手の数、スコアを、代表がキーボードで打ち込むと大きく出る。キーの受け取りと値の保存は、もうエンジンが行っている（`src/engine/keys.ts` と `src/engine/reducer.ts` の `board-key`）。部品は**表示**と**セルのクリック**だけを作る。

props:

```ts
interface BoardProps {
  heading?: string;
  cells: { label: string }[];   // 1つなら「角を折った人」のような1つの数。6つならチームのスコア
  layout?: 'single' | 'grid';   // 既定: cells が1つなら single、それ以外は grid
  unit?: string;                // 数字のあとに小さく出す。例「人」
  highlightTop?: boolean;       // true なら段階が2つになり、段階1で最大値のセルを目立たせる
  markLabel?: string;           // 印（* キー）が付いたセルに出す言葉。例「美しい賞」。省くと「★」
}
```

- `boardCells: (p) => p.cells.length` を `SceneKind` に書く（これでエンジンが数字キーをこの場面に渡す）
- `steps: (p) => p.highlightTop ? [[], ['reveal']] : [[]]`
- 値は `boardOf(state, scene.id, props.cells.length)`（`src/engine/reducer.ts` から import）で読む。`values[i]` が確定した数（なければ `null`）、`cursor` が入力中のセル、`draft` が入力中の文字（Enter で確定）、`marks` が印の付いたセルの番号
- 表示
  - 入力中のセル（`cursor`）は、`draft` があれば `draft` を、なければ `values` を出す。入力中のセルは太い枠（6px 以上、`--ink`）で分かるようにする。点滅しない
  - 値がないセルは「—」
  - single: 数字は 1920×1080 の座標で **400px 以上**。ラベルは数字の上
  - grid: 6つなら 3列×2行。数字は **120px 以上**、ラベルは 40px 以上
  - 印の付いたセルには `markLabel` の札を出す（太字、`--accent` の地に白字など、32px 以上）
  - `highlightTop` の段階1: いちばん大きい値のセル（同点は全部）を `--accent` の地にし、ほかを薄く（opacity 0.45 程度）する。変化は 0.5 秒
- セルをクリックしたら `dispatch({ type: 'board-cursor', index: i })`
- 段階1以降でも数字の入力は効く（表示も追随する）
- ワイプ（左下・右下、高さ約 320px）と重ならない位置に置く（grid は画面の上から 65% までに収める）

## 5. 完成の条件

1. `npx tsc --noEmit` と `npx vite build --outDir /tmp/wind-check-01` が通る
2. timer: 段階0で `4:00`、段階1で `stepAt` からの残りを出し、0 で止まって `endText` を出す。残りの計算を関数に切り出し、`stepAt` から 0秒・1.2秒・239.5秒・241秒たったときの表示（`4:00`・`3:58` か `3:59`（切り上げか切り捨てかを報告に書く）・`0:01` か `0:00`・`0:00`）を node で確かめて報告に書く
3. timer: 色を変える・点滅する・音を出す処理がない
4. board: `boardCells` と `steps` が上のとおり。値・入力中・印・最大値の強調が上のとおりに出る
5. board: セルのクリックで `board-cursor` を dispatch する
6. 文字の大きさ・線の太さが 00_共通 3 の決まりを守る

## 6. 妥協しない点

- 時間は `stepAt` 起点（部品の中に開始時刻を持たない）
- 生徒に見える画面に、操作の説明（「→ で始める」など）を出さない
