## 2. 場面「reveal」（予想させてから明かす）

注意を引く軸は「予測と結果のズレ」。まず予想させ、→ で明かす。

props:

```ts
interface RevealProps {
  heading?: string;           // 例「予想してみて」
  question: string;           // 問い。`**言葉**` で強調できる（rich() を使う）
  answer?: string;            // 答えの言葉。`**言葉**` で強調できる
  media?: { src?: string; slot?: string };  // ぼかしてから明かす画像（なくてもよい）
  hiddenText?: string;        // 答えが隠れているあいだに答えの場所に出す字。既定「？」
}
```

- 段階は2つ。`steps: (p) => [countEmphasis(p.question).concat(countEmphasis(p.heading)), ['reveal', ...countEmphasis(p.answer)]]`（`countEmphasis` は `basic.tsx` にある）
- 段階0: `heading`、`question`、答えの場所に `hiddenText`（太い枠の箱の中、96px 以上）。`media` があれば、画像を強くぼかして（`filter: blur(40px)` 程度、拡大して縁のにじみを隠す）出す
- 段階1: 答えの箱の中身が `answer` に変わる（0.5 秒。下から上がる・薄くから濃くの程度）。画像のぼかしが 0.6 秒で取れる
- 画像は `basic.tsx` の `MediaView` に `{ ...media, fit: 'contain' }` を渡して出す。ぼかしは外側の要素に当てる
- 配置: 画像があるときは左に画像（幅 55% 程度）、右に問いと答え。ないときは問いと答えを中央に。ワイプ（左下・右下、高さ約 320px）と重ならないよう、画面の上から 1920×1080 の座標で 680px までに収める
- 文字: 問い 64px 以上、答え 96px 以上

## 3. 場面「chapter」（進み具合・次を解放）

授業の章（例: プリント／変化／3秒で伝えろ／大学で学ぶと）を横に並べ、今から始まる章を「解放」して見せる。

props:

```ts
interface ChapterProps {
  heading?: string;
  chapters: string[];
  current: number;    // これから始まる章の番号（0 から）
}
```

- 段階は1つ。`steps: () => [['unlock']]`
- 章は横一列の大きな札（高さ 200px 程度、角丸、線は 6px 以上）。左から順に
  - 終わった章（`i < current`）: `--ink` の地に白字、右上に「済」の小さな札
  - 今の章（`i === current`）: 場面に入って 0.3 秒後から 0.5 秒かけて「鍵のかかった見た目（灰色の点線の枠、字は `?`）」から「`--accent` の地に白字で章の名前」へ変わる。変化は1回だけ（ループしない）。経過は `stepAt` から計算する（`useNow(50)` 程度）。`stepAt` から 0.8 秒以上たっていれば、最初から変わったあとの見た目で描く（リロード・戻ったときに演出をやり直さない）
  - これからの章（`i > current`）: 灰色の点線の枠、字は `?`。名前は**全部伏せる**
- 章の札の下に「`current + 1` / `chapters.length`」を 40px 程度で出す
- ワイプと重ならないよう、画面の上から 680px までに収める
- 絵文字（🔒など）は使わない（会議ツールや環境で見え方が変わるため）。鍵は線と字で表す
