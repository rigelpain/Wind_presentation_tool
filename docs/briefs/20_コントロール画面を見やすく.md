# 指示書: コントロール画面の枠を、アイコンを使って見やすくする

- 日付: 2026-10-11
- 案件: プレゼンツール
- 作成: 本社（開発の責任者の代行）
- もと: 代表の言葉（2026-10-11）「設定画面が文字ばかりで見づらく認知負荷が高いです。アイコンを併用しシンプルかつ操作性の向上に努めてください」
- 先に読む: `docs/briefs/10_コントロール画面_共通.md`、**`src/control/ui.tsx`（共通の部品。これを使う）**、`src/control/Control.tsx`（本社が先に作り直した外枠。見本）

## 1. やること

担当の枠（下の 3 節）を、**機能と動きはそのまま**、見た目だけを作り直す。dispatch する action、呼ぶ関数、確かめの `confirm`、状態の読み方は変えない。新しい機能を足さない。

## 2. 決まり（全員共通）

1. **共通の部品を使う**（`src/control/ui.tsx`）。新しい見た目の部品を自分で作らない
   - `Section`（見出し＝アイコン＋2〜6字。説明は `help` に入れ、「？」を押したときだけ出る）
   - `Row`（左にアイコン＋短い名前、右に操作）
   - `Segmented`（1つだけ選ぶもの。アイコン＋短い字、または アイコンだけ＋`title`）
   - `Slider`（`format` で単位、`reset` で標準に戻すボタン）
   - `Toggle`（入り切り）
   - `IconButton`（`title` は必ず付ける。意味が明らかならアイコンだけ）
   - `Swatches`（色）
   - `Status`（状態の印。ok / warn / bad / idle）
2. **字を減らす**
   - 見出しと名前は 2〜6 字。説明の文は、画面にいつも出さず `Section` の `help` に移す（消さない。言い回しは短くしてよい）
   - いつも出してよい文は、エラーと「いま何が起きているか」の状態だけ（`Status` で1行）
   - ボタンの字は 2〜5 字。アイコンだけのボタンには `title`（マウスを乗せたときの説明）を付ける
3. **アイコンは lucide-react**（`import { Play } from 'lucide-react'`）。同じ意味には同じアイコンを使う（下の表）
4. 並びは「よく使うものが上」。1つの `Section` には関係するものだけを入れる
5. 部品の CSS は担当の CSS ファイルに書く（共通の見た目は `ui.css` にもうある。`ui.css`・`ui.tsx`・`styles.css` は触らない）
6. 文字の大きさは 12〜16px。押せるものは高さ 28px 以上

### 同じ意味には同じアイコン

| 意味 | アイコン |
|---|---|
| 切り替え: カット / 黒を挟む / 重ねる / 横すべり | `Scissors` / `Square` / `Blend` / `MoveRight` |
| 授業のデータのまま | `Undo2` |
| ワイプ: 2人 / 右を大きく / 左だけ / 右だけ / 隠す | `Users` / `Maximize2` / `PanelLeft` / `PanelRight` / `EyeOff` |
| 時計: 出さない / 残り / 経過 / 時刻 | `EyeOff` / `Hourglass` / `Timer` / `Clock` |
| 再生 / 一時停止 / 止める / くり返す | `Play` / `Pause` / `Square` / `Repeat` |
| 足す（ファイル）/ 消す / 名前を直す | `Upload` / `Trash2` / `Pencil` |
| 上へ / 下へ / ドラッグの取っ手 / 開く | `ArrowUp` / `ArrowDown` / `GripVertical` / `ChevronDown` |
| 標準に戻す・元に戻す | `RotateCcw` |
| 位置: 自動（下）/ 上 / 自由 | `PanelBottom` / `PanelTop` / `Move` |
| 字の大きさ / 色 / 地の色 / 行間 | `Type` / `Baseline` / `PaintBucket` / `AlignVerticalSpaceAround` |

## 3. 担当ごとの組み立て（目安。決まりの範囲で変えてよい）

- **A スライド**（`SlidesPanel.tsx`・`.css`）: 1つの `Section`（`ListOrdered`「並び」、aside に「元に戻す」`RotateCcw`）。行は「取っ手・番号・名前・（種類は小さく灰色）・飛ばす（`EyeOff` のアイコンボタン、飛ばしているとき `active`）・↑・↓・開く（`ChevronDown`）」。開いた中は `Row` 3つ: 切り替え（`Segmented`、`Undo2` と4種）、ワイプ（`Segmented`、`Undo2` と5種）、音楽（選択欄のまま、`Music`）。台本のメモは `NotebookPen` を添えて小さく
- **B カメラ**（`CameraPanel.tsx`・`.css`）: `Section`「カメラ」（`Camera`。確認の映像、状態は `Status`、カメラの選択欄、始める `Power`／止める、動画で試す `FileVideo`、検出の人数と fps と見失いは小さく1行）→ `Section`「2人」（`Users`。左右の名札の入力＋色、登録 `ScanFace`（primary）、入れ替え `ArrowLeftRight`）→ `Section`「ワイプ」（`PictureInPicture2`。見せ方の `Segmented`、大きさ `Maximize2`・寄り `ZoomIn`・名札の字 `Type` の `Slider`、鏡 `FlipHorizontal2`・名札 `Tag` の `Toggle`）。顔のデータの注意などの文は `help` へ
- **C 音楽**（`MusicPanel.tsx`・`.css`）: `Section`「再生」（`Music`。曲名、再生/一時停止・止める の `IconButton`、位置の `Slider` と「1:23 / 3:45」、自動再生が止められた・鳴らす窓がないは `Status`）→ `Section`「音」（`Volume2`。音量 `Slider`、くり返す `Toggle`、フェード `Segmented`、鳴らす窓 `Segmented`（`Monitor` 表示画面 / `Laptop` この画面））→ `Section`「曲」（`ListMusic`。足す `Upload`、行ごとに 流す `Play`・名前 `Pencil`・消す `Trash2`、ドロップの受け口）。著作権などの文は `help` へ
- **D 字幕**（`CaptionsPanel.tsx`・`.css`、`CaptionBoxEditor.tsx` の文だけ）: `Section`「字幕」（`Captions`。入り切りの `Toggle`（大きめ）、状態は `Status`、マイクの音量 `MicMeter`、聞き取った文）→ `Section`「文字」（`Type`。大きさ・行間・消えるまで の `Slider`、行の数 `Segmented`、字の色・地の色 の `Swatches`、見本）→ `Section`「位置」（`Move`。`Segmented`（自動・上・自由）と位置の編集）。Google に送る・保存しないなどの文は `help` へ。`CaptionBoxEditor.tsx` は下の説明の文を短くするだけ（ドラッグの動きは触らない）
- **E 表示**（`SettingsPanel.tsx`・`.css`）: `Section`「切り替え」（`Layers`。既定の切り替え `Segmented`（アイコン＋字）、長さ `Slider`）→ `Section`「時計」（`Clock`。授業の長さ（数の入力欄のまま、`Hourglass`）、表示画面の時計 `Segmented`、授業を始める）→ 一番下に「設定を元に戻す」（`RotateCcw`）。説明の文は `help` へ

## 4. 触ってよいファイル

担当の `.tsx` と `.css` だけ（D は `CaptionBoxEditor.tsx` の文も）。ほかは触らない。

## 5. 完成の条件

1. `npx tsc --noEmit` と `npx vite build --outDir <scratchpad>/wind-check-20<担当の記号>` が通る
2. 前と同じ action・関数を、同じ条件で呼んでいる（差分を読んで確かめられるように、ロジックの行は動かしても書き換えない）
3. いつも見えている説明の文（2文以上のもの）が、枠の中に残っていない（`help` に移っている）
4. アイコンだけのボタンにすべて `title` がある
5. 2 節の表のアイコンを、表のとおりの意味で使っている

## 6. 報告

完成の条件ごとに「できた / できなかった」、変えたファイル、責任者に確認したいこと。コミットしない。ブラウザは使わない。
