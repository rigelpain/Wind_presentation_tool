## 2. 場面「flash」（ボードゲームの判定: 各チームの紙を3秒だけ映す）

props:

```ts
interface FlashProps {
  heading?: string;        // 段階0に出す題。例「3秒で伝えろ」
  slots?: string[];        // 映す写真の枠の名前。既定は teamSlot(1)〜teamSlot(6)（photos.ts）
  labels?: string[];       // 枠ごとの名前。既定「チーム1」〜「チーム6」
  seconds?: number;        // 映す秒数。既定 3。1〜5
  countFrom?: number;      // カウントダウンの最初の数。既定 3
}
```

- 段階は `1 + slots.length`。`steps: (p) => [[], ...slots.map(() => ['countdown', 'flash'])]`
- 段階0（準備）: `heading` と、枠ごとの小さな見出し（チーム番号と、写真が入っているか: 入っていれば小さな写真、なければ「まだ」）を並べる。ここだけ、映す秒数を変えるボタン（−／＋、1〜5秒）を置いてよい。秒数は `dispatch({ type: 'scene-data', sceneId: scene.id, value: { seconds } })` で保存し、`state.sceneData[scene.id]` から読む（なければ props.seconds、それもなければ 3）
- 段階 k（k ≥ 1）: 枠 `slots[k-1]` について、`stepAt` からの経過で次の3つを順に出す
  1. カウントダウン: `countFrom` から 1 まで、1秒ずつ。数字は画面の中央に **480px 以上**、地は `--ink`、字は白。数字の上に小さく（48px 程度）その枠の名前（例「チーム2」）
  2. 提示: 写真を全画面（地は黒、`object-fit: contain`、回転と明るさは `photoStyle()` を当てる）で、設定の秒数だけ
  3. 黒: 全面の黒。左上に小さく（40px 程度、灰色）枠の名前だけを出したままにする（次の段階に進むまで）
- 写真がない枠: 提示の時間に「（枠の名前）の写真がありません」を白字で出す
- R（もう一度）で、その段階のカウントダウンからやり直す（`stepAt` が更新される）
- 描き直しは `useNow(50)` 程度。カウントダウンの数字の切り替わりは時刻で決める（setTimeout の積み重ねにしない）
- 舞台にワイプは出ない前提（場面のデータで `wipe: 'hidden'` にする）。部品はワイプのことを考えなくてよい

## 3. 写真の読み込み（PhotoTray）

ボードゲームで、担任のスマホから届いた6枚の写真を、30秒以内に6チームの枠に入れる。舞台の窓でも発表者用の窓でも開く（`src/stage/Stage.tsx` と `src/presenter/Presenter.tsx` がもう呼んでいる）。

- パネルの見た目は、いまの仮の部品と同じ枠（`.panel-backdrop` > `.panel` > `.panel__head`）を使う
- 枠はチーム1〜6（`teamSlot(n)`）。3列×2行。それぞれに大きな番号、写真の小さな表示（`photoStyle()` を当てる）、ボタン「回す」（90度ずつ）、「明るく」「暗く」（brightness を 0.15 ずつ、0.5〜2.0）、「消す」
- 入れ方（どれでも入る）
  1. パネルのどこかに画像ファイルを複数まとめてドロップ → 空いている枠に、番号の小さい順に入る（`putPhotosInOrder(files, slots)`）。並びはドロップしたファイルの順
  2. ある枠の上にドロップ → その枠に入る（あれば置き換え）。複数なら1枚目だけ
  3. 「ファイルを選ぶ」ボタン（`<input type="file" accept="image/*" multiple>`）→ 1 と同じ
  4. パネルを開いているあいだ、貼り付け（⌘V）で画像を貼る → 空いている最初の枠に入る
- 枠の写真を別の枠へドラッグ → 2つの枠を入れ替える（`swapPhotos(a, b)`）
- 「全部消す」ボタン（`confirm` で確かめてから `clearAll()`）
- 画像でないファイルは無視する
- 説明の一文をパネルの上に置く（例「写真をまとめてドロップすると、チーム1から順に入ります。枠どうしはドラッグで入れ替えられます」）
- このパネルは発表者が操作するもので生徒には見せない前提なので、文字は 16px 程度でよい（00_共通 3 の 32px の決まりは、舞台の場面の部品だけに当てる）

## 5. 完成の条件

1. `npx tsc --noEmit` と `npx vite build --outDir /tmp/wind-check-02` が通る
2. flash: 段階の数と `steps` が上のとおり
3. flash: 経過時間から「カウントダウンの数字 / 提示 / 黒」を決める関数を切り出し、seconds=3・countFrom=3 で経過 0秒・0.99秒・1.0秒・2.5秒・3.0秒・5.9秒・6.0秒・10秒 のときの結果（3 / 3 / 2 / 1 / 提示 / 提示 / 黒 / 黒）を node で確かめて報告に書く
4. flash: 段階0の秒数のボタンが `scene-data` で保存し、段階1以降の提示の長さに効く
5. PhotoTray: 上の入れ方 1〜4、入れ替え、回す・明るく・暗く・消す、全部消す が photos.ts の関数を呼んでいる
6. PhotoTray: export の名前と props が変わっていない

## 6. 妥協しない点

- 時間は `stepAt` 起点
- 写真はこのブラウザの中だけ（photos.ts の IndexedDB）。外へ送る処理を書かない
