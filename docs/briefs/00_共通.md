# 指示書の共通（プレゼンツール・場面の部品）

- 日付: 2026-10-10
- 案件: プレゼンツール
- 作成: 本社（開発の責任者の代行）

部品の指示書（01〜04）を読む前に、これを読んでください。

## 1. このツール

授業（約30分、オンライン）で映すプレゼンツールです。授業は「場面」の並びで、場面ごとに部品（React の部品）を1つ選び、文面はデータ（`props`）で渡します。舞台の窓（会議ツールで共有する）は 1920×1080 の座標で描き、窓の大きさに合わせて縮めます。

## 2. 読むファイル（この範囲だけ読めば足ります）

| ファイル | 何があるか |
|---|---|
| `src/engine/registry.ts` | 部品の型 `SceneKind` と、部品が受け取る `SceneViewProps` |
| `src/engine/types.ts` | 状態 `ShowState`、演出の種類 `EffectKind` |
| `src/scenes/basic.tsx` | **見本の部品**（題・文字・画像）。`rich()`（`**言葉**` を大きく）、`MediaView`（画像・動画・読み込んだ写真を出す） |
| `src/scenes/EffectLogScene.tsx` | step で表示を変える部品の見本 |
| `src/lessons/parts.ts` | 部品の見本の授業。各部品の `props` の例がある |
| `src/styles.css` | 見た目の決まり（色の変数、文字の大きさ） |

## 3. 部品の作り方の決まり

- 部品は `SceneKind` を1つ export する。`component` が描く部品、`steps(props)` が「段階ごとに記録する演出」の配列（長さ＝段階の数）。段階は → キーで進む。段階 0 は場面に入ったとき
- `step` は、段階の数より大きい値（例: 99）で渡されることがある（場面の切り替えの黒の最中）。そのときは**最後の段階**として描く
- 時間で動くもの（カウントダウン、提示、タイマー）は、**`stepAt`（その段階に入った時刻、`Date.now()` の値）からの経過**で描く。部品の中に「始めた時刻」を持たない。こうするとリロードしても、発表者用の画面と舞台の窓でも、同じ時刻になる。描き直しは `useNow(ms)`（`src/engine/store.ts`）を使う
- 「もう一度」（R キー）は `replay` が1増え、`stepAt` が今に更新される。時間で動く部品は、これで最初からやり直す
- 部品の中で状態を変えたいときは `dispatch`（props で渡される）を使う。使える action は `src/engine/types.ts` の `Action`
- 文字は 1920×1080 の座標で **32px 以上**。線は **4px 以上**。速い点滅（1秒に3回以上の明滅）を作らない（フリッカーは指示書の間隔を守る）
- 色は `styles.css` の変数（`--paper` `--ink` `--muted` `--accent` など）を使う。新しい色を足さない
- 動きは 0.4〜0.6 秒（`var(--move)` と `var(--ease)`）。飾りの動き（揺れ、回転、跳ね）は入れない
- 音は出さない
- 部品の CSS は、部品のファイルの近くに `src/scenes/<部品名>.css` を作って、部品のファイルの先頭で `import './<部品名>.css';` する。`styles.css` は触らない。クラス名は部品名で始める（例: `.timer__digits`）

## 4. 触ってよいファイル

各指示書の「触ってよいファイル」だけ。とくに次は**触らない**（ほかの作業員と同時に動いているため）: `src/scenes/index.ts`、`src/lessons/*`、`src/engine/*`、`src/styles.css`、`package.json`。足りない機能があれば「責任者に確認したいこと」に書く。

## 5. 確かめ方

1. `npx tsc --noEmit` がエラーなしで通る
2. `npx vite build --outDir /tmp/wind-check-<部品名>` が通る（`dist/` には出さない）
3. ブラウザは使わない（ほかの作業員と同じ画面を取り合うため）。見た目の確認は監視役が行う
4. 時間の計算など、純粋な計算は関数に切り出し、`node` で数値を確かめてよい（確かめた値を報告に書く）
