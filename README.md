# Wind Presentation Tool

授業用のプレゼンツール。1台のWebカメラに映る2人の顔を追って左下・右下のワイプに切り出し、授業を「場面」の並びとして進め、注意を引く演出をいつ使ったかを記録して、最後に「設計の証拠」として見せる。

## 動かす

```bash
npm install
npm run dev
```

ブラウザ（Chrome 推奨）で2つの窓を使う。どちらで操作しても連動する。

| 窓 | URL | 使い方 |
|---|---|---|
| **表示画面** | http://localhost:5173/ | プロジェクターに映す・会議ツールで共有する。カメラと顔追尾はこの窓で動く。`F` で全画面 |
| **コントロール画面** | http://localhost:5173/#/control | 発表者の手元。いま・次の縮小表示、台本のメモ、時計、スライドの順番、カメラとワイプ、音楽、切り替えの設定 |

表示画面で `P` を押すとコントロール画面が開き、コントロール画面の「表示画面を開く」で表示画面が開く。

## 本番（Zoom で共有する）

```bash
npm run show
```

組み立てて手元（localhost:4173）で出し、表示画面とコントロール画面を Chrome のアプリの窓で開く。Chrome は専用のプロフィールで、**窓が隠れても描くのを止めない**・**音の自動再生を止めない**設定で開く（Zoom のウィンドウ共有で絵が止まらないように）。授業を選ぶときは `npm run show -- --lesson=<id>`。ネットにつながらなくても動く（顔検出のモデルと wasm は手元にあり、外へは読みにいかない）。

Zoom の手順はコントロール画面の「Zoom で共有」にもある。

1. コントロール画面の「カメラ・ワイプ」で外付けのカメラを選び、2人を映して「登録する」。Zoom 本体のビデオはオフ
2. Zoom の「共有」→「ウィンドウ」で表示画面の窓を選ぶ（コントロール画面は生徒に見えない）
3. 「ビデオクリップに最適化」をオン（ワイプと切り替えがなめらかになる）。音楽を流すなら「音声を共有」もオン
4. 表示画面は最小化しない。コントロール画面の上の帯の印が緑なら、表示画面は描けている
5. 予行で、別の端末から Zoom に入って生徒側の見え方を確かめる

### 新しい Mac で初めて使うとき

```bash
git clone https://github.com/rigelpain/Wind_presentation_tool.git
cd Wind_presentation_tool
npm install
npm run show
```

Node.js 22 以上と Google Chrome が要る。最初の1回は表示画面でカメラの許可を求められるので許可する。

授業は URL の `?lesson=<id>` で選ぶ。`?lesson=parts` は部品の見本。

## 操作

| キー | 動き |
|---|---|
| → / Space / PageDown | 進む（場面の中の次の段階も） |
| ← / PageUp | 戻る |
| E | 解説モード（解説の顔を大きく）の入り切り |
| H | カメラを隠す・戻す（コントロール画面に隠している秒数が出る） |
| W | ワイプを2人とも同じ大きさに |
| S | ワイプの左右を入れ替える |
| R | もう一度（3秒提示、タイマーなど） |
| B / . | 画面を黒にする・戻す |
| 数字 → Enter | 数のボードに入れる（↑↓でセルを移る、`*` で印） |
| F | 全画面（舞台の窓） |
| C | カメラの準備（舞台の窓） |
| P | コントロール画面を開く（表示画面） |
| U | 写真の読み込み |
| ? | 操作の一覧 |

プレゼン用のリモコンは、多くが → ← か PageDown / PageUp を送るのでそのまま使える。

## コントロール画面でできること

- **スライド**: 並べ替え（ドラッグか ↑↓）、飛ばす、場面ごとの切り替え・ワイプ・音楽の上書き、クリックでその場面へ。授業のデータには書き戻さず、このPCに残る
- **カメラ・ワイプ**: 表示画面のカメラを選ぶ・始める・止める、2人の登録（左の人・右の人の名札を自由に書く。例「進行役：小林」。名札はこのPCにだけ置く。名札の色と字の大きさも変えられる）、左右の入れ替え、ワイプの見せ方、大きさと顔への寄り、鏡、役割名
- **音楽**: 曲を足す（このPCのブラウザに置く）、再生・一時停止・止める・位置、音量、くり返し、フェード、鳴らす窓（画面共有で音を送るなら表示画面）。既定は鳴らさない
- **字幕**: 話し声を聞き取って表示画面に字幕を出す（入り切り、字の大きさ、字の色、地の色（地なしなら字に縁取り）、位置、行の数、消えるまでの秒数）。聞き取りはコントロール画面の窓のマイクで行う。日本語は Chrome がPCの中で文字にできればそうし、できなければ Google のサーバーで文字にする（無料、ネットが要る）。だれが話したかは分けない。文字は保存しない
- **切り替え・時計**: 切り替え（カット・黒を挟む・重ねる・横すべり）と長さ、授業の長さ、表示画面に出す時計（残り・経過・時刻）
- 上の帯に、いまの時刻・経過・残り・目安との差・この段階の時間・カメラを隠している秒数

## 顔の追尾

外付けのWebカメラの映像から、ブラウザの中で顔を探して2人を追う（MediaPipe の顔検出、近距離用のモデル）。全体で2人そろわないとき（離れて座っている、顔が小さい）は、画面を左右に分けて大きくしてから探し直す。カメラから 2m 以内が目安。カメラ側の自動の顔追従（オートフレーミング）は**切っておく**（ソフトの追尾とぶつかる）。

## カメラの準備（C）

1. 「カメラを始める」。カメラを選ぶ
2. 2人ともカメラに映った状態で「登録する」。画面で左に映っている人が「進行」、右の人が「解説」になる
3. 2人の位置が入れ替わったら `S`
4. カメラがないときは「カメラの代わりに動画・画像で試す」でファイルを入れて確かめられる

顔の映像はこのブラウザの中だけで使い、保存も送信もしない。カメラを隠す前と後の静止画（変化盲の答え合わせ用）も、舞台の窓のメモリにだけ置く。

## 授業の作り方

授業は `src/lessons/` の TypeScript のデータ（`Lesson`）。場面ごとに部品（`kind`）と中身（`props`）を書く。

| kind | 何をする |
|---|---|
| `title` | 題 |
| `text` | 文字。`**言葉**` で大事な言葉だけ大きく。`build: true` で1行ずつ |
| `media` | 画像・動画を大きく。→ で1枚ずつ |
| `reveal` | 予想させてから明かす（ぼかし → 種明かし） |
| `chapter` | 章の並びと、次の章の解放 |
| `timer` | 残り時間の大きな数字（音なし） |
| `board` | 数のボード（1つの数、6チームのスコア） |
| `flash` | 「3・2・1」→ 写真を N 秒 → 黒。6チームを番号順に |
| `compare` | 2枚を並べる、前後の切り替え、フリッカー、カメラを隠す前後の静止画 |
| `effect-log` | 種明かし: 使った演出の回数と時間軸 |

場面に書ける共通の項目: `wipe`（`both` / `explain` / `host` / `guest` / `hidden`）、`transition`（`cut` / `black` / `fade` / `slide`）、`music`（曲の id か `stop`）、`notes`（発表者用の窓だけに出る台本）、`plannedSec`（目安の秒数）、`opensLoop` / `closesLoop`（「答えはあとで」の問いを開く・回収する）。

人や建物が写る写真、実際の授業の台本は `public/private/` と `src/lessons/private/` に置く（どちらもリポジトリに入らない）。

## 演出の記録

演出が発動するたびに「いつ・どの演出・どの場面」を記録する（授業を始めてから）。演出の名前と理由は `src/engine/effects.ts`。軸は「予測と結果のズレ」と「注意は動き・顔・大きさに引かれる」。

## 守ること

- 顔のデータは保存も送信もしない
- 細い線・小さい字・速い点滅・細かい模様を使わない（会議ツールの圧縮で崩れる）
- 学校名、先生の名前は、リポジトリにも画面にも書かない。ワイプの名札は役割名（実名は出さない）
